Web Technologies

HTML

HTML stands for HyperText Markup Language, is the standard language used to create and build web pages.
It acts as the structural skeleton of a website by telling a web browser how to display text, images, and other content.
The language uses special codes called tags to organize information into headings, paragraphs, and links.

CSS

CSS stands for Cascading Style Sheets, and it is a core language used to build websites.
It controls how a webpage looks by changing things like colors, fonts, layout, and spacing.
While HTML creates the actual structure and text of a website, CSS is what makes it beautiful and visually appealing to users.

JavaScript

JavaScript is a programming language used to build interactive websites.
It allows developers to add features like moving graphics, pop-up menus, and web games.
By using this language, creators can turn static text pages into dynamic and exciting experiences for users.

AFrame

A-Frame is an open-source web framework used for building virtual reality experiences in a web browser.
It allows developers to create 3D scenes using simple HTML tags instead of writing complex JavaScript code.
Because it runs directly on the web, users can view these interactive 3D worlds on computers, smartphones, and VR headsets without installing any extra software.
