Computer Programming and Web Design

The Computer Programming and Web Design CTE program is all about teaching you how to build the digital world.
In this program, you will learn the secret languages behind your favorite websites, apps, and games.
You will start by designing beautiful webpages using HTML and CSS, and then move on to writing code using popular programming languages like Python and JavaScript.
It is a highly hands-on course where you get to problem-solve, create your own digital projects, and gain the exact tech skills needed for high-paying careers in software development and web design.
